# Experiment Module

An `activate_experiment` event details the data needed to trigger an Adobe Target experience by pushing data to the datalayer from server side or client side events.

## How to Implement

<Tabs>
  <Tab label="TypeScript">
    ```ts title="index.ts"
    interface Experiment {
    event: 'activate_experiment';
    experiment: {
            exp_id: string;
            exp_name: string;
            var_id: string;
            var_name: string;
            type: 'A/B Test' | 'Personalisation' | 'Pop-up';
        }
    }

    // Example Event
    const experiment: Experiment = {
        event: 'activate_experiment',
        experiment: {
            exp_id: '706141',
            exp_name: 'PLAT | AU - Test User Split',
            var_id: '1',
            var_name: 'Experience A',
            type: 'A/B Test'
        }
    }
    if( window.xpDatalayer ) { xpDatalayer.push(experiment) }
    ```
  </Tab>
