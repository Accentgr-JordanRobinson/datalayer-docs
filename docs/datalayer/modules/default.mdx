# Default Module

The `default` module contains all the core information fo the app. This is further broken down into `site`, `page`, `user` & `loyalty` data.

>[!INFO]
>The default data only needs to be pushed to the data layer if any of the following conditions are met;
>1. The app has been loaded for the first time (ie. The user opens the website in their browser marking the start of their session).
>2. The DOM has been rerendered (ie. The application is being rendered as a Static Site & the user navigates to a page triggering a page reload).
>3. Any information has changed  (ie. If a user navigates from 'Home' page to 'Products' page the `page.type` will be updated from "home" to "product").
